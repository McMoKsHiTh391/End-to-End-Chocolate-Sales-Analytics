🚀 Project Overview

This project focuses on analyzing chocolate sales performance through data cleaning, transformation, SQL analysis, and interactive BI dashboards.
The goal is to identify key revenue drivers, top-selling products, customer trends, and overall business performance.

🛠️ Tech Stack Used

PostgreSQL – Data cleaning, transformation, SQL queries

Power BI – Dashboard creation & visual analytics

DAX – Custom measures and KPIs

Excel/CSV – Raw dataset (if applicable)
